GLOBAL NEWS — DEMO NEWS PORTAL
================================

HOW TO RUN
1. Extract the global-news.zip file.
2. Open Visual Studio Code.
3. Select File > Open Folder.
4. Choose the extracted "global-news" folder.
5. Open index.html.
6. Recommended: install the "Live Server" extension in VS Code.
7. Right-click index.html and choose "Open with Live Server".

FEATURES
- Responsive editorial homepage
- Demo stories in js/app.js
- Category filtering
- Search by title, summary, category or author
- Article detail modal
- Save/bookmark stories using LocalStorage
- Dark/light mode preference using LocalStorage
- Trending stories
- Load more stories
- Demo newsletter form
- Mobile navigation
- Share story (uses browser share where available)

IMPORTANT
This first version uses sample/demo article content and remote Unsplash images.
It is not connected to a live news service. The newsletter form is a front-end demo
and does not send or store email addresses. To publish real news, replace the sample
stories in js/app.js with verified reporting or connect a news API in a later step.

CUSTOMIZE
- Website title and metadata: index.html
- Colours, typography and layout: css/style.css
- News content and behaviour: js/app.js

No build tools or npm installation are required.
